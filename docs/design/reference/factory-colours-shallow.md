# Factory colours: shallow pass

Scope: the 45 roster cars **not** covered by the deep passes (roster numbers 22, 36, 38, 40-52,
54-63, 67-70, 72, 75-88, 90, 92-94 are handled elsewhere). These are the cars nobody
squints at: a Corolla, a Familia, a kei van. Each gets four to eight plausible period colours with a
plain shade description, because consolidation across manufacturers can only work from descriptions.

**Confidence labels.**

- **sourced** - a real colour list was found for this car (or this exact model family and era) and the
  pool below is that list, trimmed. URL cited.
- **typical** - no list was found in the search budget. The pool is what a car of this maker, class,
  price point and era was ordinarily sold in. Honest placeholder, not evidence.

Search budget for this pass was two searches per car. Depth on any one car was deliberately not
spent; anything marked typical is a candidate for a later pass if it ever matters.

## Counts

45 cars covered.

- **sourced: 25** - a real colour list was found and the pool is that list.
- **typical: 20** - no list found inside the budget; the pool is a labelled placeholder.

Roster numbers marked typical: 1, 2, 4, 5, 8, 10, 11, 12, 13, 16, 17, 18, 20, 24, 29, 30, 33, 35,
64, 91.

Note on the sourced set: a couple of lists are market-specific rather than JDM-specific and say so
in the entry (the Civic EF2 list is the EF generation's factory list; the E36 M3 list is European).
They are still real lists rather than invention.

Where a typical pool felt like a stretch (weakest first): Honda City E (AA), Nissan S-Cargo, Ferrari
512 TR, Nissan Laurel C33. Everything else marked typical is a mainstream car in a class with a
well-understood period palette, so the placeholder is low-risk.
